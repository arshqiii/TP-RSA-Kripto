## Deskripsi Proyek

Proyek ini merupakan tugas pemrograman untuk mata kuliah **CSCE 604243 Cryptography & Information Security**. Program ini bertujuan untuk melakukan enkripsi dan dekripsi file menggunakan skema **RSA-OAEP-256** dengan panjang kunci **2048 bit**.

Program dirancang agar dapat memproses berbagai jenis file, tidak hanya teks biasa, tetapi juga file binary seperti gambar, audio, video, dokumen, dan executable file.

## Ketentuan Tugas

Berdasarkan deskripsi tugas, program harus memenuhi beberapa ketentuan berikut:

- Mengimplementasikan enkripsi dan dekripsi RSA-OAEP-256.
- Menggunakan panjang kunci 2048 bit.
- Program dibuat menggunakan Python.
- Program menerima dua file input:
  - file plaintext/ciphertext
  - file key dalam format hexadecimal
- Program menghasilkan satu file output:
  - ciphertext untuk proses enkripsi
  - plaintext untuk proses dekripsi
- Program memiliki GUI.
- Program diuji dengan berbagai jenis dokumen, seperti text, image, audio, video, dan binary file.
